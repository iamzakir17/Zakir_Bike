ZAKIR MOTORS — PREMIUM BIKE SHOWROOM

1. Unzip this folder.
2. Open index.html in your browser.
3. Every navigation link opens the selected section/page in a NEW TAB as requested.

Files:
- index.html      -> Home
- about.html      -> About
- bikes.html      -> Bike collection (7 bikes)
- services.html   -> Ride essentials / helmets / riding gear
- contact.html    -> Contact + demo enquiry form
- style.css       -> Main design system
- script.js       -> Mobile menu + demo contact form
- assets/images/  -> Your attached photos

Attached images used:
- hero-rider.png          -> hero / riding experience
- showroom-collection.png -> showroom + bike collection visuals
- rider-community.png     -> rider community / lifestyle section

NOTE FOR YOUR OWN LOCAL PHOTOS:
Replace any image file inside assets/images/ with your own photo using the same filename, or edit the image path in the HTML.
